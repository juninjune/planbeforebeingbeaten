# Quickstart: 울타리 치기 1인 플레이 검증

## 준비

- Node 22 이상, pnpm
- e2e에는 Aside 브라우저와 `aside` CLI가 필요하다.

```bash
pnpm install
```

## 실행

```bash
pnpm dev
```

출력된 주소(기본 `http://localhost:5173`)를 연다. 로비에서 울타리 치기를 누르면 판이 열린다.

## 엔진 테스트

```bash
pnpm test
```

기대 결과: 판정, 리듀서, 풀이기, 생성기(크기별 100개 유일해, 같은 시드 재현) 테스트가 모두 통과한다.

## 브라우저 e2e

개발 서버가 떠 있는 상태에서 실행한다.

```bash
e2e/run.sh
```

390x844 화면 크기에서 5x5, 7x7, 10x10 각각에 대해 다음을 확인한다.

1. 로비에서 게임에 들어가 판이 열린다.
2. 정답에서 변 하나를 뺀 상태로는 완성 화면이 나오지 않는다(고리 미완성).
3. 닫힌 고리지만 숫자가 맞지 않는 상태로는 완성 화면이 나오지 않는다.
4. 정답을 모두 그으면 완성 화면과 기록 시간이 나온다.

기대 결과: 마지막 줄에 `E2E PASS`가 출력되고, `e2e/screenshots/`에 크기별 시작 화면과 완성 화면
스크린샷이 생긴다(`fence-5-start.png`, `fence-5-complete.png` 등 6장).

## 손으로 확인

- 주소의 `seed` 값을 그대로 두고 새로 고치면 같은 판이 나온다.
- 완성 화면에서 새 판을 누르면 다른 판이 나오고 타이머가 처음부터 시작된다.
- 화면 하단에 비공식 팬 프로젝트 고지가 보인다.
