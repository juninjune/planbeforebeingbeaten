# Data Model: 울타리 치기 1인 플레이

모든 값은 JSON으로 직렬화할 수 있는 일반 객체와 배열이다.

## 격자 좌표와 변 번호

- 판 크기 `n`은 한 변의 칸 수다(5, 7, 10). 칸은 `n × n`, 점은 `(n+1) × (n+1)`.
- 칸 번호: `r * n + c` (`r`은 위에서부터 행, `c`는 왼쪽에서부터 열).
- 변은 모두 `2 * n * (n + 1)`개이고, 번호는 다음과 같다.
  - 가로 변 `H(r, c)`: 점 `(r, c)`와 `(r, c+1)`을 잇는다. `r`은 0부터 `n`, `c`는 0부터 `n-1`. 번호 `r * n + c`.
  - 세로 변 `V(r, c)`: 점 `(r, c)`와 `(r+1, c)`를 잇는다. `r`은 0부터 `n-1`, `c`는 0부터 `n`. 번호 `n * (n + 1) + r * (n + 1) + c`.
- 칸 `(r, c)`의 네 변: `H(r, c)`, `H(r+1, c)`, `V(r, c)`, `V(r, c+1)`.

## Puzzle

| 필드 | 타입 | 설명 |
|---|---|---|
| `size` | `5 \| 7 \| 10` | 한 변의 칸 수 |
| `seed` | `string` | 판 식별값. 고정 퍼즐은 `"fixed"` |
| `clues` | `(0 \| 1 \| 2 \| 3 \| null)[]` | 길이 `size * size`. `null`은 숫자 없음 |

규칙: 답(선이 그어진 변의 집합)이 정확히 하나다.

## EdgeMark

`0` 빈 변, `1` 선, `2` X 표시.

## FenceState

| 필드 | 타입 | 설명 |
|---|---|---|
| `marks` | `EdgeMark[]` | 길이 `2 * size * (size + 1)` |
| `history` | `{ edge: number; prev: EdgeMark }[]` | 되돌리기 기록. 가장 최근이 마지막 |
| `solved` | `boolean` | 완성 여부. `true`가 되면 이후 행동은 무시 |

## FenceAction

| 행동 | 효과 |
|---|---|
| `{ type: "cycle", edge }` | 해당 변을 0 → 1 → 2 → 0 순으로 바꾸고 기록에 추가. 바꾼 뒤 판정해 `solved` 갱신 |
| `{ type: "undo" }` | 기록의 마지막 항목을 꺼내 그 변을 이전 값으로 복원. 기록이 없으면 그대로 |
| `{ type: "clear" }` | 모든 변을 0으로, 기록을 비움 |

상태 전이: `solved`가 `false → true`로만 바뀐다. `solved`인 상태에서는 어떤 행동도 상태를 바꾸지 않는다.
범위를 벗어난 `edge`는 무시한다.

## 정답 판정 조건

선(`1`)으로 표시된 변만 본다. 다음을 모두 만족하면 정답이다.

1. 선이 하나 이상 있다.
2. 모든 점에서 그 점에 닿은 선의 수가 0 또는 2다.
3. 선들이 하나로 이어져 있다(임의의 선에서 출발해 점을 따라가면 모든 선에 닿는다).
4. 숫자가 있는 모든 칸에서 네 변 중 선의 수가 숫자와 같다.
