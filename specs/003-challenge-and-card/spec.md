# Feature Specification: 도전장 링크와 결과 카드

**Feature Branch**: `main`
**Created**: 2026-11-22
**Status**: Draft
**Input**: 완성한 판과 내 기록을 링크와 이미지로 공유하고, 받은 사람이 같은 판에서 그 기록에 도전한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 도전장을 보내고 받는다 (Priority: P1)

완성 화면에서 공유를 누르면 판과 내 기록이 담긴 링크가 만들어진다. 받은 사람이 링크를 열면 같은
판이 열리고 도전 기록이 보인다. 완성하면 도전 기록과 비교한 결과가 나온다.

**Acceptance Scenarios**:

1. **Given** 완성 화면, **When** 공유를 누른다, **Then** 판의 크기와 식별값, 내 기록 시간, 힌트 횟수가 담긴 링크가 보인다.
2. **Given** 도전장 링크, **When** 연다, **Then** 보낸 사람이 푼 것과 같은 판이 열리고 도전 기록이 표시된다.
3. **Given** 도전장으로 연 판, **When** 도전 기록보다 빨리, 도전자의 힌트 횟수 이하로 완성한다, **Then** 도전 성공과 시간 차이가 나온다.
4. **Given** 도전장으로 연 판, **When** 도전 기록보다 늦게 완성한다, **Then** 도전 실패와 시간 차이가 나온다.
5. **Given** 도전장으로 연 판, **When** 도전자보다 힌트를 더 써서 완성한다, **Then** 시간과 무관하게 힌트를 더 썼다는 결과가 나온다.
6. **Given** 오늘의 판을 공유한 링크, **When** 같은 날 연다, **Then** 오늘의 판으로 열린다. 다른 날 열면 같은 판이 자유 판으로 열린다.
7. **Given** 도전 기록 값이 잘못된 링크, **When** 연다, **Then** 도전 표시 없이 일반 판으로 열린다.

---

### User Story 2 - 결과 카드를 만든다 (Priority: P2)

완성 화면에서 고리 모양, 기록, 힌트 횟수, 서비스 주소가 담긴 이미지를 만들어 공유하거나 저장한다.

**Acceptance Scenarios**:

1. **Given** 완성 화면, **When** 공유를 누른다, **Then** 결과 카드 이미지가 보인다.
2. **Given** 공유 화면, **When** 이미지 저장을 누른다, **Then** 카드가 이미지 파일로 저장된다.
3. **Given** 공유 화면, **When** 링크 복사를 누른다, **Then** 링크가 복사되고 복사됐다는 표시가 나온다. 복사가 막힌 환경에서는 링크가 선택된 채 보여 직접 복사할 수 있다.
4. **Given** 기기의 공유 창을 쓸 수 있는 브라우저, **When** 공유하기를 누른다, **Then** 기기의 공유 창이 링크(가능하면 이미지와 함께)로 열린다.

### Edge Cases

- 고정 퍼즐(`seed=fixed`)은 공유할 수 있지만 도전 기록 비교는 일반 판과 같게 동작한다.
- 도전 기록과 정확히 같은 시간이면 무승부로 표시한다.
- 링크의 도전 값은 서버 검증이 없어 꾸며낼 수 있다. 형식이 맞는지만 확인한다.
- 도전장으로 연 판을 완성하고 다시 공유하면 내 기록으로 새 도전장이 만들어진다.

## Requirements *(mandatory)*

- **FR-001**: 완성 화면에 공유 수단이 있어야 한다.
- **FR-002**: 도전장 링크는 판의 크기, 식별값, 도전 기록 시간, 힌트 횟수를 담아야 한다.
- **FR-003**: 도전장 링크를 열면 같은 판과 도전 기록이 보여야 한다.
- **FR-004**: 도전장으로 연 판을 완성하면 성공, 실패, 무승부, 힌트 초과 중 하나의 결과가 나와야 한다.
- **FR-005**: 형식이 맞지 않는 도전 값은 무시해야 한다.
- **FR-006**: 결과 카드는 고리 모양, 기록, 힌트 횟수, 판 크기, 서비스 이름과 주소를 담아야 하고 자체 제작 그래픽만 써야 한다.
- **FR-007**: 링크 복사와 이미지 저장은 모든 브라우저에서 제공해야 한다.
- **FR-008**: 오늘의 판을 공유한 링크는 날짜가 지나도 같은 판을 열어야 한다.

## Success Criteria *(mandatory)*

- **SC-001**: 모바일 화면 크기에서 "완성 → 공유 → 링크 열기 → 같은 판과 도전 기록 → 완성 → 결과"가 브라우저 자동 테스트로 통과한다.
- **SC-002**: 형식이 틀린 도전 값 10가지 이상이 모두 무시되는 것이 자동 테스트로 확인된다.
- **SC-003**: 결과 카드 이미지가 파일로 남고 눈으로 확인된다.
- **SC-004**: 기존 브라우저 자동 테스트가 모두 그대로 통과한다.
- **SC-005**: 배포 주소에서 도전장 링크가 열린다.

## Assumptions

- 서버 저장, 랭킹, 판마다 다른 링크 미리보기 이미지, 소리는 범위 밖이다.
- QR 코드는 넣지 않는다.
