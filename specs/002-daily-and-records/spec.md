# Feature Specification: 오늘의 판과 내 기록

**Feature Branch**: `main`
**Created**: 2026-11-22
**Status**: Draft
**Input**: 울타리 치기에 하루 한 판씩 모두가 같은 판을 푸는 "오늘의 판"과, 기기에 남는 "내 기록"을 더한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 오늘의 판을 푼다 (Priority: P1)

사용자가 로비나 게임 화면에서 오늘의 판에 들어간다. 한국 시간으로 같은 날에는 누구나 크기별로
같은 판을 받는다. 오늘의 판에서는 힌트를 쓸 수 없다. 이미 푼 크기는 푼 것으로 표시된다.

**Independent Test**: 같은 날짜와 크기로 만든 판이 같고 다른 날짜는 다른지 자동 테스트로 확인한다.
브라우저에서 오늘의 판을 풀고 로비로 돌아가 푼 표시를 확인한다.

**Acceptance Scenarios**:

1. **Given** 로비, **When** 오늘의 판 7x7을 누른다, **Then** 오늘 날짜가 표시된 7x7 판이 열리고 힌트 버튼은 없다.
2. **Given** 한국 시간 날짜가 같은 두 사람, **When** 같은 크기의 오늘의 판을 연다, **Then** 숫자 배치가 같다.
3. **Given** 날짜가 다른 두 날, **When** 같은 크기의 오늘의 판을 연다, **Then** 숫자 배치가 다르다.
4. **Given** 오늘의 판 7x7을 완성한 상태, **When** 로비나 게임 화면을 본다, **Then** 7x7이 푼 것으로 표시되고 다른 크기는 그대로다.
5. **Given** 이미 푼 오늘의 판, **When** 다시 연다, **Then** 다시 풀 수 있지만 이미 풀었다는 안내와 그때의 기록이 보이고, 오늘의 기록은 처음 것 그대로다.
6. **Given** 게임 화면, **When** 오늘의 판과 자유 판을 오간다, **Then** 자유 판에서는 힌트 버튼이 있고 오늘의 판에서는 없다.

---

### User Story 2 - 내 기록이 남는다 (Priority: P2)

판을 완성하면 크기별 최고 기록, 푼 판 수, 오늘의 판 연속 일수가 기기에 저장되고, 새로 고치거나
다시 방문해도 남아 있다.

**Independent Test**: 기록 갱신 규칙을 자동 테스트로 확인한다. 브라우저에서 판을 완성하고 새로 고친
뒤 기록이 남아 있는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 기록이 없는 크기, **When** 힌트 없이 완성한다, **Then** 그 시간이 최고 기록이 되고 푼 판 수가 1이 된다.
2. **Given** 최고 기록이 있는 크기, **When** 힌트 없이 더 빨리 완성한다, **Then** 최고 기록이 바뀌고 완성 화면에 갱신 표시가 나온다.
3. **Given** 어떤 크기, **When** 힌트를 써서 완성한다, **Then** 푼 판 수만 늘고 최고 기록은 그대로다.
4. **Given** 어제 오늘의 판을 푼 사용자, **When** 오늘 오늘의 판을 하나 푼다, **Then** 연속 일수가 1 늘어난다.
5. **Given** 오늘 이미 오늘의 판을 하나 푼 사용자, **When** 다른 크기의 오늘의 판을 푼다, **Then** 연속 일수는 그대로다.
6. **Given** 그저께 이후로 오늘의 판을 풀지 않은 사용자, **When** 화면을 본다, **Then** 연속 일수는 0으로 보이고, 오늘 풀면 1이 된다.
7. **Given** 기록이 있는 기기, **When** 새로 고친다, **Then** 기록이 그대로 보인다.

### Edge Cases

- 기기 저장소를 쓸 수 없으면(사생활 보호 모드 등) 기록 없이 게임은 그대로 동작한다.
- 저장된 값이 깨져 있으면 빈 기록으로 시작한다.
- 판을 열어 둔 채 자정을 넘기면, 그 판은 연 날짜의 오늘의 판으로 기록된다.
- 고정 퍼즐(`seed=fixed`)은 기록에 넣지 않는다.
- 오늘의 판 날짜는 기기의 표준 시간대와 무관하게 한국 시간으로 정한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 오늘의 판은 한국 시간 날짜와 판 크기로만 정해져야 한다.
- **FR-002**: 로비와 게임 화면에서 크기별 오늘의 판에 들어갈 수 있어야 한다.
- **FR-003**: 오늘의 판에서는 힌트를 제공하지 않아야 한다.
- **FR-004**: 오늘 이미 푼 크기는 로비와 게임 화면에서 푼 것으로 표시돼야 한다.
- **FR-005**: 완성 시 크기별 최고 기록, 푼 판 수, 오늘의 판 연속 일수를 기기에 저장해야 한다.
- **FR-006**: 힌트를 쓴 판은 최고 기록을 바꾸지 않아야 한다.
- **FR-007**: 오늘의 판의 그날 기록은 처음 완성한 것으로 고정돼야 한다.
- **FR-008**: 게임 화면은 현재 크기의 최고 기록과 푼 판 수를, 로비는 연속 일수를 보여줘야 한다.
- **FR-009**: 저장소를 쓸 수 없거나 값이 깨져 있어도 게임은 동작해야 한다.

### Key Entities

- **오늘의 판**: 한국 시간 날짜(연-월-일)와 크기로 정해지는 판.
- **내 기록**: 크기별 최고 기록과 푼 판 수, 날짜별 오늘의 판 완성 내역, 연속 일수와 마지막으로 푼 날짜.

## Success Criteria *(mandatory)*

- **SC-001**: 같은 날짜와 크기의 오늘의 판은 100% 같고, 연속한 30일의 판은 크기별로 모두 서로 다르다.
- **SC-002**: 모바일 화면 크기에서 "로비 → 오늘의 판 → 완성 → 로비에 푼 표시와 연속 1일 → 새로 고쳐도 유지"가 브라우저 자동 테스트로 통과한다.
- **SC-003**: 같은 자동 테스트에서 힌트를 쓴 완성이 최고 기록을 만들지 않고 푼 판 수만 늘리는 것이 확인된다.
- **SC-004**: 기존 브라우저 자동 테스트가 모두 그대로 통과한다.
- **SC-005**: 배포 주소에서 오늘의 판에 들어갈 수 있다.

## Assumptions

- 기록은 기기에만 저장한다. 서버 랭킹, 계정, 기기 간 동기화는 범위 밖이다.
- 지난 날짜의 오늘의 판을 다시 여는 기능은 없다.
- 도전장, 결과 카드, 소리는 범위 밖이다.
